# Runa Skills Index

Runa maintains nine primary owner skills here. The separately authored customer product lives under docs/runa/maintainer/customer-agent/skills. Assess both products for reusable rules and public capability changes.

| Skill        | Load when                                                                                  |
| ------------ | ------------------------------------------------------------------------------------------ |
| `backend`    | General backend/application design, failure paths, dependencies, side effects, refactoring |
| `laravel`    | Laravel framework, Eloquent, validation, routes, jobs/scheduler/console                    |
| `frontend`   | Accessibility, responsive UX, design-system discipline, rendered acceptance                |
| `vue`        | Vue 3 Composition API, reactivity, components, routing, async behavior                     |
| `tailwind`   | Tailwind version syntax, tokens, utilities, responsive layout, build verification          |
| `postgresql` | PostgreSQL schema, indexes, migrations, query planning, concurrency                        |
| `security`   | Secure coding, browser/security boundaries, supply chain, security review                  |
| `docker`     | Dockerfile/Compose/devcontainer/production container behavior                              |
| `rag`        | Qdrant/embeddings/ingestion/retrieval/evaluation/project knowledge                         |

## Loading rule

Read the active roadmap first.

Load only the skill(s) required for the current point.

Then load only the needed files under that skill's `references/`.

Do not load all nine skills for every task.

## Authority

Runa project rules and active roadmap decisions override generic/upstream skill guidance.

See `docs/runa/handbook/ai/skills-policy.md`.
