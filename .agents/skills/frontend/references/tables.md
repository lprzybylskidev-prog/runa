# Tables reference

The authoritative delivered contract is [the public tables guide](../../../../docs/runa/handbook/development/frontend/tables.md). Load it only for the current task. Maintain platform capability contracts there and owner-specific implementation decisions in the active owner roadmap. Customer application patterns belong in their local App guidance; extracting application controls never authorizes protected-source edits.

Table data columns sort by default; use sortable: false to opt out and preserve
server capability allowlists. Compare date instants rather than localized text.
Use the public tables guide for the complete contract.
