# Component Catalogue

No reusable application components exist in the pre-implementation package yet. Add entries only when working components are introduced.

For each shared component record its name, source path, purpose, when it must be preferred over native/other controls, important props/events/behavior and real canonical usage examples. Update or remove obsolete entries when a component is replaced or deleted. Search the catalogue and source before creating a new control; never fabricate paths or build unused components just to fill this catalogue.
