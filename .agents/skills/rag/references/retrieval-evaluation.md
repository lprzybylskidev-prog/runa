# Retrieval and evaluation

Follow [the public knowledge procedure](../../../../docs/runa/handbook/development/knowledge.md)
for supported search/read/status, explicit intent, bounded source diversity,
section expansion, citations, diagnostic modes and golden reports.

Use short English semantic/identifier queries for the pinned baseline. Choose
current guidance, historical decisions or audit comparison deliberately. Read
original and superseding evidence; report retrieved facts, deductions and gaps
separately. A score, hash, Git revision or index time never establishes truth.

Freeze representative required sources/sections before changing retrieval. Compare
the same budgets and expectations, including unknowns/contrary sources, source
diversity and latency. Probe-only failures stay visible and cannot replace required
cases. Doctor/freshness and selected final AI gates remain strict. Real-service
acceptance belongs to final verification, not routine implementation points.
