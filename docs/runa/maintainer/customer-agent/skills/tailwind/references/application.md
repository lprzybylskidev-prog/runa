# Application tailwind guidance

Verify the installed Tailwind version. Use semantic tokens and complete static class names; preserve responsive/light/dark/focus states. Application CSS/overrides remain application-owned and must work through the supplied static/native error presentation contract.

Load only the relevant canonical procedure:

- Frontend architecture: `docs/runa/handbook/architecture/frontend.md`.
- Selected palette: `docs/runa/handbook/design/color-palette.md`.
- Presentation and CSS replacement: `docs/runa/handbook/development/frontend/customization.md`.

Maintain application-specific patterns in local guidance/docs/app. Ordinary App
code and optional app modules are supported; copied owner files or a Contracts
namespace never authorize platform/internal APIs. Preserve installed local
extensions during reviewed updates. This default contains no owner-only procedure.
