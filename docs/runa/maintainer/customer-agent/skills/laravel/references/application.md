# Application laravel guidance

Use installed-version Boost guidance for uncertain framework APIs. Keep routes named, controllers thin, validation in Form Requests and substantial work in Actions. Ordinary App code and optional app modules remain equally supported.

Load only the relevant canonical procedure:

- Application composition: `docs/runa/handbook/architecture/application-architecture.md`.
- Supported CLI and host transport: `docs/runa/handbook/tooling/commands.md`.
- Tests and isolated database lifecycle: `docs/runa/handbook/testing/strategy.md`.
- Explicit seeding/contributors: `docs/runa/handbook/data/seeding.md`.
- Optional module contracts: `docs/runa/handbook/development/modules.md`.
- Guarded public APIs: `docs/runa/handbook/architecture/public-api.md`.

Maintain application-specific patterns in local guidance/docs/app. Ordinary App
code and optional app modules are supported; copied owner files or a Contracts
namespace never authorize platform/internal APIs. Preserve installed local
extensions during reviewed updates. This default contains no owner-only procedure.
