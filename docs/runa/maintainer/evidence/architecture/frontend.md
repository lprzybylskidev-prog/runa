# Owner procedure and historical evidence

Source classification: `docs/runa/handbook/architecture/frontend.md`. These owner-only procedures and dated execution records are retained separately from customer guidance. Historical claims keep their original context; current public operations are documented in the handbook.

Polish Laravel validation/localization resources are required from the start for user-facing messages. Technical backend output, machine codes and admin messages remain English. The approved implementation uses pinned vendored translation data with Laravel’s native loader; no `laravel-lang/lang` or `laravel-lang/common` dependency is permitted. Provenance, MIT attribution and deliberate update instructions are in `docs/runa/maintainer/development/localization.md`.

Reuse suitable project controls instead of native replacements, including date inputs, selects, labels, errors and actions. The ApplicationLayout workspace hierarchy is heading/description/actions, breadcrumbs, optional statistics, optional toolbar, then mandatory content, with an optional supplementary panel. The sidebar stays viewport-fixed and scrolls independently; the top header remains visible while the toolbar scrolls normally. These shell features were implemented and visually accepted in RM-2026-004 point 3; business modules remain deferred.

Temporary visual review infrastructure was retired in RM-2026-004 point 22 after owner acceptance. The application registers no `/__review/...` or test-fixture routes in any environment; the catalog, review controllers, review-mail namespace and Vite review configuration are removed. Former public/ui-review output is deleted and excluded from Docker context. The welcome `/` entry, reusable library, layouts, native errors and mail engine remain. Browser tests use isolated `src/runa/tests/frontend/fixtures/browser` scenarios through the loopback-only Playwright harness, with generated bundles under `.runtime/browser-harness`, never public/ or the production graph. There is no permanent showcase or application preview switch.

Compact contexts use optional sm Select/TextInput/NumberInput controls (36px), matching sm Buttons, with ordinary forms retaining md defaults. Table's default toolbar provides whole-table Search plus page size; custom filters remain optional. Optional TableQuery.search survives view snapshots and reaches server providers as filter[search]. TablePreferences uses an Available views selector with Default view first, then all saved views, and compact numeric width fields initially populated by Table's measured column-widths event. Automatic-width reset removes explicit sizing. The Auth-owned durable per-user preference requirement, including locale/theme/views and cross-browser continuity, is recorded in [deferred-module-concerns.md](../../maintainer/architecture/deferred-module-concerns.md); current persistence remains browser-local.

Integrated checks cover screen-reader-facing Chromium accessibility names/roles/states and label/error references, real keyboard interactions, focus containment/return, minimum visible control targets, theme-token contrast, reduced motion and print. The 200% reflow case uses a separate 720×450 CSS-pixel context at DPR 2, equivalent to a 1440×900 desktop at 200% for layout/text size; it is not a native browser-menu zoom or manual NVDA/VoiceOver certification. See docs/runa/maintainer/testing/strategy.md for exact coverage and limits.

The customer welcome entry lives in `src/app/resources/`; the protected UI library, styles, assets and native error/mail renderers live in `src/runa/resources/`. Shared styles scan both resource roots. The public `@/runa/ui` facade and its subpaths resolve before customer `@/` imports in Vite, TypeScript and Vitest. Internal platform code may use `@runa/`; customer code consumes the public facade. Application-only controls do not require a layout/router/provider. Production Vite output lives at `src/public/build/`; source test harnesses remain outside the production build graph. See [Application Architecture](../../maintainer/architecture/application-architecture.md#delivered-source-and-runtime-composition) for view/translation overrides and dependency ownership.
