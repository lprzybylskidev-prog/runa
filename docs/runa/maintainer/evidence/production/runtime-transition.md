### Historical PHP candidate evaluation

The production-only PHP runtime now uses official `php:8.4.27-fpm-alpine3.24` at index digest `sha256:93aa3f61216b73cc6f878235c9772849449f4efc18dfe3d6678eed645076c00d`. Development retains the existing Debian/browser toolchain. The production dependency stage installs Composer/unzip on Alpine; neither enters the final image. Required PDO PostgreSQL, mbstring, intl/full ICU data, bcmath, OPcache, pcntl, ZIP, cURL and XML capabilities remain mandatory. UID/GID, FPM configuration, read-only mounts, startup validation, storage layout and health/worker/scheduler behavior keep their established contracts.

The upstream Alpine PHP image uses GNU iconv rather than musl iconv. Final-image probes explicitly check Polish iconv/Laravel transliteration, multibyte text and ICU ordering; decimal/XML/ZIP/HTTPS/process support; required extensions, exact PHP version, UTC/non-root identity, assets and absence of development material. They also check FPM configuration. These probes are executed by the existing production build/image/self-test path; their source fixture remains operator tooling and is never copied into runtime images.

Host verification of the Alpine candidate found GNU libiconv 1.18 transliterates `Zażółć gęślą jaźń` as `Zaz'ol'c ge'sla ja'z'n` under all four tested locales; glibc's iconv produces `Zazolc gesla jazn` under the development UTF-8 locale. Laravel `Str::ascii(..., 'pl')` consistently returns `Zazolc gesla jazn`. Application source currently has no direct iconv/transliteration calls. The operator probe now asserts the exact reviewed implementation-specific iconv output plus a lossless UTF-8/UTF-16LE round trip, and keeps the exact application-facing Laravel assertion. Unknown implementations still fail. Do not use native iconv transliteration output as a cross-runtime identifier/slug contract; establish explicit application behavior when such a feature is introduced. This is a documented native-library difference, not an application behavior regression or final image acceptance.
