# Admin foundation tests

EntryTest prepares real target-platform Core installation, session login, ordinary
direct grants, password proof and guarded bootstrap. It authors expiry, foreign
proof/session/security-version, revocation, maintenance/Core failure and safe
diagnostic projection cases. Source/runtime declarations and explicit initial
update history are covered without claiming native installer or rendered acceptance.

During pre-release development, this fixture selects the specified 0.7.0 runtime
for availability/update planning without changing platform VERSION or source data.
Use the supported owner backend runner with explicit module path or native name
filter and a disposable worker. The common fixture removes exact Admin registration
and update history before removing its Core prerequisites. No Admin tables exist.
Complete suites/browser/native installation/update acceptance remain final-only.
